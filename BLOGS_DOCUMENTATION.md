## 1. Overview

The **Blogs Module** provides an end-to-end content publishing and management system for Anwar Clinic, inspired by the architecture from `rhinon-cms`. It spans three core services:
- **Backend (`backend/`)**: PostgreSQL / Sequelize ORM model, RBAC authorization, administration endpoints, and public-facing cached APIs.
- **Admin Panel (`admin-panel/`)**: Next.js App Router, TipTap WYSIWYG rich text editor, FAQ builder, metadata controls, media library integration, and permission-guarded routes.
- **Landing Page (`landing_page/`)**: Next.js App Router, dynamic SEO metadata, category filtering, live search, social sharing, interactive FAQ accordion, and conversion-optimized consultation CTAs.

## 3. Database Layer

- **File:** [`backend/src/models/Blog.ts`](file:///d:/Projects/anwar_clinic/anwar_clinic/backend/src/models/Blog.ts)
- **Table Name:** `blogs`

#### Schema Attributes

| Field Name | Type | Modifiers / Constraints | Description |
|---|---|---|---|
| `id` | `UUID` | Primary Key, Default: `UUIDV4` | Unique post identifier |
| `slug` | `STRING(255)` | Not Null, Unique, Indexed | URL-friendly unique slug |
| `title` | `STRING(255)` | Not Null | Article headline |
| `excerpt` | `TEXT` | Nullable | Short summary / intro teaser |
| `content` | `TEXT` | Nullable | HTML content generated by TipTap |
| `contentBlocks` | `JSONB` | Nullable, Default: `[]` | Structured block content storage |
| `faqs` | `JSONB` | Nullable, Default: `[]` | Array of `{ question: string, answer: string }` |
| `category` | `STRING(100)` | Not Null, Default: `'General'` | Main article category |
| `tags` | `JSONB` | Nullable, Default: `[]` | Array of string tags (e.g. `["FUE", "Recovery"]`) |
| `authorName` | `STRING(100)` | Not Null, Default: `'Dr. Anwar'` | Author display name |
| `authorRole` | `STRING(100)` | Nullable | Author designation (e.g. `'Lead Surgeon'`) |
| `authorAvatar` | `STRING(500)` | Nullable | Avatar image URL |
| `coverImage` | `STRING(500)` | Nullable | Feature/hero cover image URL |
| `readTime` | `STRING(50)` | Nullable, Default: `'5 min read'` | Estimated read time badge |
| `publishedAt` | `DATE` | Nullable | Official publication timestamp |
| `status` | `ENUM('draft', 'published')` | Not Null, Default: `'draft'` | Publication workflow state |
| `featured` | `BOOLEAN` | Not Null, Default: `false` | Highlighted post indicator |
| `metaTitle` | `STRING(255)` | Nullable | Custom SEO meta title |
| `metaDescription` | `TEXT` | Nullable | Custom SEO meta description |
| `views` | `INTEGER` | Not Null, Default: `0` | View count tracker |
| `sortOrder` | `INTEGER` | Not Null, Default: `0` | Manual ordering weight |
| `createdById` | `UUID` | Nullable, Foreign Key | Refers to `users.id` |
| `createdAt` | `DATE` | Not Null | Created timestamp |
| `updatedAt` | `DATE` | Not Null | Updated timestamp |

#### Associations
- **File:** [`backend/src/models/index.ts`](file:///d:/Projects/anwar_clinic/anwar_clinic/backend/src/models/index.ts)
- `Blog.belongsTo(User, { as: 'createdBy', foreignKey: 'createdById' })`

## 4. Backend Implementation

### 4.1. RBAC Permissions Configuration
- **File:** [`backend/src/config/permissions.ts`](file:///d:/Projects/anwar_clinic/anwar_clinic/backend/src/config/permissions.ts)
- Registered permissions:
  - `blogs:read`: View blogs in admin panel.
  - `blogs:write`: Create, edit, publish, and delete blog posts.
- Configured defaults:
  - `superadmin`: All permissions including `blogs:read` and `blogs:write`.
  - `doctor`: Clinical permissions plus `blogs:read` and `blogs:write`.

### 4.2. Administration Routes (`/blogs`)
- **File:** [`backend/src/routes/blogs.ts`](file:///d:/Projects/anwar_clinic/anwar_clinic/backend/src/routes/blogs.ts)
- Guarded with `authMiddleware` + `requirePermission`:

| Method | Endpoint | Permission | Description |
|---|---|---|---|
| `GET` | `/blogs` | `blogs:read` | List all blogs with pagination, search, status, and category filtering |
| `GET` | `/blogs/:id` | `blogs:read` | Get single blog by UUID for editing |
| `POST` | `/blogs` | `blogs:write` | Create a new blog post; auto-resolves slug duplicates (`slug-1`, `slug-2`) |
| `PUT` | `/blogs/:id` | `blogs:write` | Full update of blog post fields; preserves or updates slug |
| `PATCH` | `/blogs/:id/toggle-status` | `blogs:write` | Quick toggle between `'draft'` and `'published'` |
| `DELETE` | `/blogs/:id` | `blogs:write` | Deletes the specified blog post |

### 4.3. Public Website Routes (`/public/blogs`)
- **File:** [`backend/src/routes/public.ts`](file:///d:/Projects/anwar_clinic/anwar_clinic/backend/src/routes/public.ts)
- Unauthenticated endpoints for the public landing page:

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/public/blogs` | Lists all blogs where `status = 'published'`, sorted by `featured DESC, publishedAt DESC`. Supports `?category=...` and `?search=...`. |
| `GET` | `/public/blogs/:slug` | Fetches article by slug where `status = 'published'`. Automatically increments `views` counter and returns up to 3 related articles matching the same category. |

### 4.4. Seed Script
- **File:** [`backend/src/config/seedBlogs.ts`](file:///d:/Projects/anwar_clinic/anwar_clinic/backend/src/config/seedBlogs.ts)
- Seeds 4 initial clinical articles if the `blogs` table is empty:
  1. *FUE vs. FUT Hair Transplant: Which Technique Is Right for You?*
  2. *The Complete Hair Transplant Recovery Timeline: Day 1 to Month 12*
  3. *PRP Therapy for Hair Loss: Scientific Evidence, Process & Results*

- Automatically hooked into database initialization in [`backend/src/server.ts`](file:///d:/Projects/anwar_clinic/anwar_clinic/backend/src/server.ts).

## 9. Operational Guide (How-To)

### 9.1. Creating a New Blog Post
1. Log in to the Admin Panel (`http://localhost:3100`) as an authorized user (`superadmin` or `doctor`).
2. Navigate to **Blogs** in the sidebar.
3. Click the **+ Write Blog** button in the upper right.
4. Enter the article title. Click **Generate Slug** (or let it auto-generate).
5. Enter a concise excerpt summarizing the key takeaway.
6. Write the body content using the **TipTap Editor**:
   - Use Heading 2 / Heading 3 for structure.
   - Insert links, lists, blockquotes, and images from the clinic Media Library.
7. Add clinical FAQs in the **FAQ Accordion Builder** at the bottom of the main column.
8. In the **Right Sidebar**:
   - Select or type a Category.
   - Add Tags (press Enter after each tag).
   - Click **Select Cover Image** to pick a high-res image from the Media Library.
   - Fill in Author details and check the Google SERP preview.
   - Toggle **Featured** if the post should appear in the hero spotlight.
9. Click **Publish Article** (or save as Draft).

### 9.2. Editing or Unpublishing an Article
1. Open **Blogs** from the sidebar.
2. In the table, click the **Edit** icon on any row to open the editor.
3. To quickly toggle status without opening the full editor, click the **Status toggle icon** (eye icon) directly in the table row.
